# CBJQ_HugFenny<br>抱走芬妮！

这是一个优化器，可以帮你抱走芬妮。

> 你需要装有 *Shizuku / Sui* 才能运行本APP。

正在开发中...

## 安装

1. 安装本APP。
2. 在 *Shizuku / Sui* 中授权本APP。

## 使用

> 在开始之前，请确保你的 *Shizuku / Sui* 已经正确安装并运行，且已授权本APP。

1. 观察启动提示，未出现报错即可继续。
2. 点击切换按钮左侧的数字，可以刷新当前的开关状态。
3. 点击切换按钮右侧的数字，可以切换开关状态。
